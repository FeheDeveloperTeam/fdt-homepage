# 작업 완료 기준

이 저장소의 모든 변경은 아래 절차를 마쳐야 완료로 간주합니다.

1. 변경한 기능과 프로젝트 안내 문서를 최신화한다.
2. 변경 범위에 맞는 확인을 수행하고, 기본적으로 `npm run lint`와 `npm run build`를 실행한다.
3. 일반 검증과 별개로 최종 재점검을 한 번 더 수행한다. 이때 변경 diff, 기능 회귀, 남은 죽은 코드·스타일, 문서와 검증 결과의 누락을 확인한다.
4. 발견한 문제를 먼저 수정한 뒤 변경 사항을 커밋하고, 현재 브랜치의 GitHub upstream으로 push한다.

push가 실패하면 작업이 완료되었다고 안내하지 않고, 실패 원인과 필요한 후속 조치를 기록한다.
